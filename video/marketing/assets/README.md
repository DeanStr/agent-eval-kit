# Original demo assets

`arc-lamp.png` is an original image generated with OpenAI imagegen for this fictional storefront. It contains no third-party branding. The storefront, code patch, scores, user story and checkout are animated illustrations, not a recording of an implemented commerce app or a measured evaluation run.

`InterVariable.woff2` is Inter 4.1 by Rasmus Andersson, downloaded from https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1. Its SIL Open Font License is included in `Inter-LICENSE.txt`. The renderer embeds both assets and waits for the font before capturing frames; it makes no runtime network requests.
